# Domain docs

Before exploring a task, read the relevant root `CONTEXT.md` and ADRs in `docs/adr/` when they exist. If neither exists, proceed silently; create them only when a domain decision or terminology is actually resolved.

This is a single-context repository. Use terminology from `CONTEXT.md` in issue titles, test names, and code. Surface any conflict with an ADR instead of silently overriding it.
